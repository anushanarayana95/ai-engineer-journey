# News API Analyzer

## Project Overview

This project fetches real-time news headlines using NewsAPI and analyzes the data using Pandas.

## Features

* Fetches top news headlines
* Extracts title, source, and publication date
* Converts JSON data into a Pandas DataFrame
* Performs basic analysis
* Exports results to CSV

## Technologies Used

* Python
* Requests
* Pandas
* NewsAPI
