# ETH Price Analysis

## Objective

Analyze Ethereum historical price data using Pandas and Matplotlib.

## Dataset

ETH hourly price dataset containing:

* Open
* High
* Low
* Close
* Volume

## Technologies Used

* Python
* Pandas
* Matplotlib

## Analysis Performed

* Data inspection
* Datetime conversion
* Monthly resampling
* Day-of-week analysis
* Moving averages
* Price visualization

## Charts

* ETH Closing Price
* ETH Trading Volume
* Average Close Price by Day

## Key Learnings

* Working with DatetimeIndex
* Using resample()
* Using groupby()
* Creating moving averages
* Saving charts with Matplotlib
