# Financial Variance & Cohort Analysis

A synthetic financial reporting project using Python/Pandas and SQL.

## What this project covers

- Actual vs budget comparison
- Revenue variance and variance percentage
- Gross-profit variance
- Regional analysis
- Cohort analysis
- Material variance identification
- SQL reporting queries
- Data validation and aggregation

## Business question

Where are actual financial results different from budget, and which regions or cohorts need further investigation?

## Tools

- Python
- Pandas
- SQL
- CSV

## Interview explanation

"I created a synthetic monthly financial dataset containing actual and budget revenue, COGS and marketing assumptions across regions and customer cohorts. I used Pandas to calculate revenue variance, variance percentage and gross-profit variance, then summarized the results by region and cohort. I also wrote SQL queries to reproduce the reporting logic and flag material variances."

## Important

All figures are synthetic and are not company or client financial data.
