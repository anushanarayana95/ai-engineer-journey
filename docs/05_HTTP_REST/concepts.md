## HTTP Methods

### GET
Used to read data without changing anything.

Example:
- /analytics
- /search

### POST
Used to create or trigger actions.

Example:
- /sync-news

### Why methods matter
They define:
- behavior of API
- safety of data
- structure of backend systems
